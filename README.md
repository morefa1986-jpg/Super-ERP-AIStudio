# 🐟 سامانه جامع مدیریت و پایش هوشمند مزرعه خاویاری فتحی (FATHI AQUA SUPER ERP v4.5)

سامانه جامع پیشرفته جهت مدیریت متمرکز زیست‌توده (Biomass)، پارامترهای هیدروشیمی آب، جابجایی گله‌ها، تغذیه خودکار، ثبت تلفات، سونوگرافی، فرآوری خاویار، حسابداری شیلاتی و دژبانی.

---

## 🚀 ویژگی‌های کلیدی
- **پایش آنی استخرها و سالن‌ها**: نقشه زنده تعاملی سالن‌های نرسری، پیش‌پروار و مولدین.
- **محاسبه دوز تغذیه و ضریب تبدیل غذایی (FCR)**: بر اساس دما، اکسیژن و میانگین وزن گله.
- **کنترل کیفی هیدروشیمی و سونوگرافی**: ثبت دما، pH، اکسیژن محلول، نیتریت، آمونیاک و تشخیص جنسیت پایه.
- **همگام‌سازی آفلاین و پشتیبان‌گیری ابری**: پشتیبانی از پایش آفلاین و همگام‌سازی خودکار با **Firebase Firestore** و **Cloud SQL**.
- **گزارش‌گیری و صادرات**: صدور شناسنامه CITES با کد QR، خورجی چاپی، PDF و اکسل (Excel/CSV).
- **بارگذاری تدریجی (Code Splitting)**: استفاده از React Lazy & Suspense جهت سرعت بارگذاری حداکثری و بهینه‌سازی حجم اسکریپت‌ها.

## 🛠️ پیش‌نیازها
- **Node.js**: نسخه 18 یا بالاتر
- **npm**: نسخه 9 یا بالاتر

---

## 📦 نصب و راه اندازی

### ۱. نصب وابستگی‌ها
جهت نصب کاملاً دقیق و انطباق با فایل `package-lock.json`:
```bash
npm ci
```
یا
```bash
npm install
```

### ۲. اجرای حالت توسعه (Development)
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس قرار می‌گیرد.

---

## 🏗️ ساخت نسخه تولید (Production Build)

جهت کامپایل پروژه و ساخت خروجی‌های بهینه‌شده:
```bash
npm run build
```
خروجی‌ها در پوشه `dist/` قرار می‌گیرند.

### اجرای نسخه تولید (Start)
```bash
npm start
```
