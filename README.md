# 🐟 سامانه جامع مدیریت و پایش هوشمند مزرعه خاویاری فتحی (FATHI AQUA SUPER ERP v5.2 Offline)

سامانه جامع پیشرفته جهت مدیریت متمرکز زیست‌توده (Biomass)، پارامترهای هیدروشیمی آب، جابجایی گله‌ها، تغذیه خودکار، ثبت تلفات، سونوگرافی، فرآوری خاویار، حسابداری شیلاتی و دژبانی.

---

## 🚀 ویژگی‌های کلیدی
- **پایش آنی استخرها و سالن‌ها**: نقشه زنده تعاملی سالن‌های نرسری، پیش‌پروار و مولدین.
- **محاسبه دوز تغذیه و ضریب تبدیل غذایی (FCR)**: بر اساس دما، اکسیژن و میانگین وزن گله.
- **کنترل کیفی هیدروشیمی و سونوگرافی**: ثبت دما، pH، اکسیژن محلول، نیتریت، آمونیاک و تشخیص جنسیت پایه.
- **عملکرد کاملاً آفلاین و پشتیبان‌گیری نسخه‌دار**: تمام عملیات اصلی روی رایانه یا شبکه محلی فارم انجام می‌شود و هیچ سرویس ابری برای کارکرد سامانه لازم نیست.
- **راه‌اندازی اولیه کامل فارم**: تعریف یا ویرایش سالن‌ها و استخرها، شکل و ابعاد، حجم آب، ظرفیت زیست‌توده، دما، اکسیژن، pH و منبع آب پیش از ورود به پنل اصلی.
- **موجودی تفصیلی هر استخر**: ثبت چند نژاد در یک استخر بر اساس جنسیت، تعداد، وزن متوسط و شماره چیپ اختیاری با کنترل چیپ تکراری.
- **گزارش‌گیری و صادرات**: صدور شناسنامه CITES با کد QR، خورجی چاپی، PDF و اکسل (Excel/CSV).
- **بارگذاری تدریجی (Code Splitting)**: استفاده از React Lazy & Suspense جهت سرعت بارگذاری حداکثری و بهینه‌سازی حجم اسکریپت‌ها.
- **اتوماسیون اداری و دفتر اندیکاتور**: نامه‌های ورودی/خروجی، زنجیره پاسخ، Tickler، پیوست و خروجی Excel/PDF.
- **فاکتور و پیش‌فاکتور حرفه‌ای**: شماره خودکار/دستی، چند ردیف، مالیات و تخفیف، مبلغ به حروف، سربرگ، تکثیر، ابطال و تبدیل پیش‌فاکتور.
- **تردد بار و باسکول**: ورود و خروج خودرو، اعتبارسنجی پلاک و تلفن، بارنامه، حواله، وزن، رسید انبار و پیوست عکس/سند.
- **تم سه‌بعدی Glassmorphism سراسری**: پس‌زمینه اختصاصی سرمه‌ای، نورهای فیروزه‌ای/بنفش، کارت‌های شیشه‌ای، فرم‌ها و جدول‌های نورانی با حفظ خوانایی فارسی.

## 📦 نصب و راه اندازی

### ۱. نصب وابستگی‌ها
جهت نصب کاملاً دقیق و انطباق با فایل `package-lock.json`:
```bash
npm ci
```
یا
```bash

```

### ۲. اجرای حالت توسعه (Development)
```bash
npm run dev
```
برنامه در آدرس `http://localhost:3000` در دسترس قرار می‌گیرد.

## 🪟 ساخت نصب‌کننده آفلاین ویندوز

روی Windows 10/11 x64 اجرا کنید:

```powershell
npm ci
npm run lint
npm run test:core
npm run desktop:make
```

فایل‌های `Fathi-Aqua-SuperERP-Setup.exe` و `Fathi-Aqua-SuperERP.msi` در مسیر `out/make` ساخته می‌شوند. گردش‌کار `.github/workflows/windows-installer.yml` نیز با اجرای دستی یا ایجاد tag نسخه، همین خروجی‌ها را روی Windows runner می‌سازد. نصب‌کننده و برنامه پس از ساخته‌شدن برای اجرا هیچ اتصال اینترنتی لازم ندارند.

برای امضای دیجیتال محلی، مسیر گواهی و رمز آن را فقط در متغیرهای امن `WINDOWS_CERTIFICATE_FILE` و `WINDOWS_CERTIFICATE_PASSWORD` قرار دهید. در GitHub Actions، محتوای Base64 گواهی PFX و رمز را در secrets با نام‌های `WINDOWS_CERTIFICATE_BASE64` و `WINDOWS_CERTIFICATE_PASSWORD` ثبت کنید. بدون گواهی نیز فایل ساخته می‌شود، ولی Windows ممکن است هشدار ناشر ناشناس نشان دهد.

## 🖥️ اجرای دائم در سرور شبکه محلی

نسخه نصب‌شده با آرگومان `--server` بدون پنجره اجرا می‌شود، در صورت توقف ناخواسته سرور داخلی را دوباره راه می‌اندازد و فقط در شبکه محلی کار می‌کند. PowerShell را با دسترسی Administrator باز کنید:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\install-server-startup.ps1 -InstallPath "C:\path\to\FathiAquaSuperERP.exe" -Port 3000
```

برای حذف اجرای خودکار (بدون حذف داده‌ها):

```powershell
.\scripts\uninstall-server-startup.ps1
```

## 💾 پشتیبان‌گیری و پایگاه داده

- **SQLite تراکنشی**: داده سرور در `fathi-aqua.sqlite` با WAL و همگام‌سازی کامل دیسک ذخیره می‌شود.
- **ذخیره‌سازی محلی مرورگر**: کلاینت حتی هنگام قطع شبکه داخلی نیز قابل استفاده است و تغییرات را در صف محلی نگه می‌دارد.
- **همگام‌سازی محلی**: اطلاعات می‌تواند در شبکه داخلی فارم با سرور محلی همگام شود؛ اتصال اینترنت لازم نیست.
- **بک‌آپ نسخه‌دار**: خروجی بک‌آپ شامل ساختار سالن‌ها، مشخصات استخرها، موجودی تفصیلی و سوابق راه‌اندازی است و در نسخه جدید قابل بازیابی و مهاجرت است.
- **بک‌آپ خودکار سرور**: هنگام شروع برنامه و سپس پیش از تغییرات دوره‌ای، snapshot معتبر SQLite ساخته می‌شود و ۳۰ نسخه آخر نگهداری می‌شود.
- **مسیر پایدار ارتقا**: در دسکتاپ داده‌ها بیرون پوشه نصب و در مسیر `userData` ویندوز ذخیره می‌شوند؛ نصب نسخه جدید آن‌ها را پاک نمی‌کند. در حالت سرور مسیر پیش‌فرض `%ProgramData%\FathiAquaSuperERP` است.
- در اولین اجرای نسخه جدید، فایل قدیمی `sturgeon_database.json` در صورت داشتن داده، خودکار به SQLite منتقل می‌شود و فایل قدیمی حذف نمی‌شود.
- فایل `sturgeon_database.json` عمداً به‌صورت قالب خالی منتشر می‌شود؛ اطلاعات واقعی فارم را فقط از بخش تنظیمات و فایل بک‌آپ معتبر وارد کنید.
- مدیر می‌تواند بدون پاک شدن داده‌ها از مسیر «تنظیمات ← عملیات پیشرفته ← بازکردن دوباره راه‌انداز اولیه» ساختار سالن‌ها، مشخصات استخرها یا موجودی آغازین را اصلاح کند.
